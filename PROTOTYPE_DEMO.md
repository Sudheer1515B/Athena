# Athena USB prototype demo — 2 minutes

## Before the audience arrives

- Keep both ESP32 boards connected to the Mac and wired as in `pwm_receiver/README.md`. No servos or external servo power are needed.
- Confirm the WDR bench is `/dev/cu.usbserial-0001` (CP2102) and the independent PWM receiver is `/dev/cu.usbserial-10` (CH340). Names can change after reconnection; `check_pwm.py` verifies USB IDs before commanding anything.
- Close Arduino Serial Monitor, miniterm, and any other program holding either serial port. If Athena is connected to the bench in Settings, click **Disconnect** before the terminal check.
- From the workspace root, start the local service in Terminal A:

  ```sh
  .venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8080
  ```

- Open `http://127.0.0.1:8080` in a browser. Keep Terminal B open alongside it.

## Live sequence

1. **Show the recorded-log conversion.** Open Athena's **Profile** page, import `RCOU.csv`, use the proposed 40–44 s window, 50 fps, and C1–C4 → OUT0–OUT3. Click **Compile & validate**. Point out the source/command traces, **200 frames**, 4-second cycle, and **SUM16 16982**. This profile is compiled and previewed, not uploaded.
2. **Show four real electrical outputs.** In Terminal B, run:

   ```sh
   .venv/bin/python -u pwm_receiver/check_pwm.py
   ```

   The safe check commands four different live widths on the stopped WDR bench, while the second ESP measures the actual signal wires. The verified result was commanded `1100,1300,1700,1900` µs and measured `1100,1297,1694,1891` µs, each with a 20,000 µs period.
3. **Show preservation.** The script sends `STOP`, then prints state `STOPPED`, all outputs `1500`, the original committed profile still `frames=100`, and unchanged lifetime `cycles=21 run_s=24 active_s=23,23,23,6`. It does not send `LOAD`, `COMMIT`, `START`, or `CLEAR`.

Optional: before step 2, connect the bench from Athena **Settings** and show its real lifetime counters on the Dashboard, then **Disconnect** before running the terminal check. Opening USB has reset this ESP32 during testing, but its profile and counters survived. Do not present the 21 cycles as newly generated by Athena.

## What to say

> “Athena turns a recorded drone log into a validated four-channel servo command profile. The Flutter interface shows the exact 200-frame replay and checksum. For the hardware proof, a second ESP independently measures each PWM output: all four channel commands arrive as real 50 Hz pulses, and the bench returns to idle afterward. This is our USB prototype. Full flight-profile playback over Wi-Fi and saved run history are the next integration step.”

## Important boundary

**Do not click “Upload to USB bench” for this preservation demo.** WDR `LOAD` discards the current committed 100-frame profile, and the protocol has no readback command to save it first. The compiled flight profile has not been replayed on hardware. The `check_pwm.py` demonstration validates the physical output path using reversible `SET` commands; it does not increment cycle counters. No servo motion or actuator life has been measured.
